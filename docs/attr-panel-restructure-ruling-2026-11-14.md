# 裁定：印章详情页属性区重构（去重复表单 ＋ 悬停勘誤 ＋ 详情模态框）

- 状态：**已裁定**（Kevin 2026-11-14 CST，第 4 点按钮位置由 clarify 选定＝B）
- 性质：非规范。供实现 / 规范 / 质检单作唯一口径真源。

## 一、口径（Kevin 原话五条）

1. 移除 `face-entry` 容器：其中表单与其它位置重复，不再需要。
2. 移除 `face-block__sub-head` 容器及其中【勘誤】按钮；该按钮改为**鼠标悬停才出现**，显示在各条属性附近。
3. `detail__table` 若普通用户可见 ⇒ 改变展示方式：把【當前展示值】【來源】【待審覈】放进**模态框**，模态框由**点击该条属性**打开，且模态框内也有【勘誤】按钮。
4. 在**印面块标题旁那排按钮**（編輯固定屬性 / 重新上傳印面圖 / 人工智能修復）附近，为**普通用户**加一个【勘誤】按钮，点击弹出**当前的多条属性一次性提交**勘誤模态框。
5. 第 2、3 点的【勘誤】是**新功能**：弹窗内只需提交**针对当前这一条属性**的一条勘误。

## 三、目标结构（每个印面块内，自上而下）

```
① 印面块标题行（badge: base face / side face）＋ 按钮排：
     編輯固定屬性 | 重新上傳印面圖 | 人工智能修復 | 設為 base face | 【勘誤】← 新增（普通用户可见）
② 固定属性区（既有，不动）
③ 属性列表（取代 detail__table）：每条一行
     行内容 ＝ 属性名 ＋ 当前展示值（摘要）
     · 鼠标悬停该行 ⇒ 行尾浮现【勘誤】按钮（默认不可见）
     · 点击行本体（非按钮）⇒ 打开「属性详情模态框」
④ 属性详情模态框（新）：
     · 展示：當前展示值 / 來源 / 待審覈（原表格三列的内容，不改口径）
     · 底部：【勘誤】（单条）＋ 关闭
```

- **`detail__table` 整块删除**（不留第二种展示）。
- **`face-entry` 整块删除**（表单、提交钮、feedback、样式；仅服务它的 state 与函数一并删，不留死代码）。
- **`face-block__sub-head` 整块删除**（含其【勘誤】与未登录提示句）。
- 两种勘誤入口语义区分：
  - **③/④ 的单条勘誤**：只针对当前属性一条 ⇒ 打开勘誤模态框时**该字段已选中且锁定**（不得再改选其它字段）；提交后仍是既有 `submitCorrection` 链路（`PENDING`）。
  - **① 的多条勘誤**：即既有 `openCorrection(face)` 的多字段一次性提交，**普通用户可见**（不是管理员专属）。

## 四、悬停按钮的可访问性（硬要求）

- 默认 `opacity:0` / `visibility:hidden`，但**键盘可达**：行内按钮在 `:focus-visible` 时同样显示；触摸设备（无 hover）⇒ 必须始终可见或用行点击进入详情框后操作（二选一，实现方选一种并写清）。
- 不得用 `display:none` 隐藏（会让键盘与读屏都无法触达）。
- 行本体可点击 ⇒ 必须是真 `button` 或带 `role="button"` ＋ `tabindex="0"` ＋ Enter/Space 可激活；点击行与点击行内【勘誤】不得互相误触（按钮内 `@click.stop`）。

## 五、不可动项

- 勘误提交链路（`submitCorrection`）与载荷键面；`PENDING → ACCEPTED/REJECTED` 状态机；`/my/corrections` 面。
- 卡片 DTO 14 键；`PUBLIC_OPS` 4 / `PUBLIC_WRITE_OPS` 1；`ADMIN_OPS` 44；`reason` 零新增字面值。
- `[data-admin-action]` 取值集合**仍恰 12 值**（新按钮一律用 `data-action`，不进该族）。
- 固定属性区、影像区、实物照片区、AI 修复、设 base face、删除印章等既有能力全部保留。
- 上屏文案一律繁体。

## 六、验收

1. 详情页 DOM：`.face-entry` **0**、`.face-block__sub-head` **0**、`.detail__table` **0**；样式表中对应选择器同样 0。
2. 每条属性行：默认看不到【勘誤】；`hover` 或键盘聚焦后可见可点。
3. 点击属性行 ⇒ 打开属性详情模态框，内含该属性的當前展示值／來源／待審覈三栏 ＋ 【勘誤】。
4. 点该【勘誤】⇒ 弹窗中**只有这一条字段可选且已选中**（其余字段不可选）；提交走 `submitCorrection`，落 `PENDING`。
5. 印面块标题旁【勘誤】**普通用户可见**（未登录 ⇒ 走登录引导，非隐藏/置灰冒充）；点击 ⇒ 打开既有多条属性提交模态框（可多选）。
6. `[data-admin-action]` 仍恰 12 值；既有套件除已知基线红外全绿。
7. 干净浏览器（零本机镜像）打开 `AACQG`：属性可见、三栏内容与改前一致（数值不得丢、来源标识不得变）。
