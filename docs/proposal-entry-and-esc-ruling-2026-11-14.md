# 裁定：印人提案入口迁出详情页 ＋ 模态框 ESC 取消

- 状态：**已裁定**（Kevin 2026-11-14 CST，两条原文见第一节）
- 性质：非规范。供实现 / 规范 / 质检单作唯一口径真源。

## 一、口径（Kevin 原话）

1. 把印章详情页（如 `/xiai/seal/AACQG`）的【提交印人提案】按钮**移除**；这个按钮应出现在：作者的【勘誤】模态框中，或首页【上传印章】模态框中，或 `/persons` 页面中的入口。
2. 模态框中按【ESC】＝用户取消输入，可以退出。

- 按钮实体在 `src/views/SealDetailView.vue` 约 3240–3252（落点在「可標記屬性」区，与登录态解耦、一律渲染）；内联提案表单在同一文件约 3256–3335（`proposalOpen` 控制，仅目标印面渲染一份）。
- `src/views/PersonIndexView.vue:51-52` 的 `collectGuide` 文案指向「請進入任一印章詳情頁…點『提交印人提案』」⇒ 入口挪走后**这句会变成死路，必须同批改**。
- `src/components/UploadSealDialog.vue:160` 已有文案「請選擇作者（印人）；庫中無此人請先提交印人提案，再回來上傳。」但**没有按钮** ⇒ 只说不给路。
- ESC 现状：只有 `PersonPicker.vue:344` 有 `@keydown.esc.prevent`、`HeaderSearch.vue:199` 处理 Escape。其余模态框（`ConfirmDialog` / `ConfirmActionDialog` / `FaceFixedAttributesDialog` / `AddSealFaceDialog` / `UploadSealDialog` / `SealFolderPicker` / `ShareDialog`，以及 `SealDetailView` / `PointsView` 内的弹窗）**均无 ESC 退出**。

## 三、入口迁移（三处，缺一不可）

提案表单抽成**可复用组件**（建议 `src/components/PersonProposalDialog.vue`），三处共用同一实现，**不得复制三份表单**：

| 落点 | 触发条件 | 说明 |
|---|---|---|
| **A. 作者勘誤模态框** | 作者检索**无命中**时露出「提交印人提案」按钮 | 这是原场景（库中无此人）的正确落点；点开即弹提案对话框 |
| **B. 首页【上传印章】模态框** | 作者检索无命中时露出同一按钮 | 把 `UploadSealDialog:160` 的「只说不给路」补成真入口 |
| **C. `/persons` 页面** | 页面控制条常驻入口（登录态解耦：未登录点击走登录引导，**不得 CSS 隐藏 / disabled 冒充**） | 同时改写 `collectGuide` 文案，不得再指向详情页 |

- 详情页：**删除按钮与内联表单**（含 `proposalOpen` / `proposal` / 相关提交函数与样式）。若某函数仅服务于该入口，一并删除；不得留下死代码。
- 提案提交后的行为保持既有口径（提交 ⇒ `PENDING` ⇒ 管理员在 `/my/corrections`「待審印人提案」采纳/驳回）；**不新增 op、不新增 reason 字面值、不改提案载荷键面**。
- `/persons` 采纳/驳回区块仍在 `/my/corrections`，本单不动。

## 四、ESC 语义（全模态框统一）

- 打开任一模态框（`role="dialog"`）后按 **ESC ⇒ 等同「取消」**：关闭弹窗、丢弃未提交的输入、不发任何写请求。
- **正在提交（busy / submitting）时 ESC 不生效**，避免半提交状态；提交完成后恢复。
- 只关**最上层**模态框（嵌套时按栈序，一次 ESC 关一个）。
- 实现必须是**单点**（一个可复用的组合式函数或指令，如 `useEscToClose`），各模态框接同一入口；**不得每个组件各写一套 keydown 判断**。
- ESC 不得影响：已提交成功的提示、页面级 notice、表单外部（非模态）区域的键盘行为。

## 五、不可动项

卡片 DTO 14 键；`PUBLIC_OPS` 4 / `PUBLIC_WRITE_OPS` 1；`[data-admin-action]` 仍恰 12 值（本单不新增该族取值）；`ADMIN_OPS` 44（本单零新增 op）；提案载荷与回包键面；`reason` 零新增字面值；上屏文案一律繁体。

## 六、验收

1. `AACQG` 详情页：「可標記屬性」区**无**「提交印人提案」按钮；DOM 里零命中。
2. 详情页提交作者勘误 → 检索一个不存在的名字 ⇒ 出现【提交印人提案】按钮 ⇒ 点开可提交 ⇒ 落 `PENDING`。
3. 首页【上传印章】→ 作者检索无命中 ⇒ 同一按钮出现、可提交。
4. `/persons` 页头旁有常驻入口、可打开提案对话框；页内引导文案不再指向详情页（grep 该句零命中）。
5. 任一模态框（确认框 / 固定属性 / 新增印面 / 上传印章 / 选择器 / 分享 / 提案）按 ESC ⇒ 关闭且无写请求（Network 零写入）；`busy` 状态按 ESC 无反应。
6. `/persons` 水合中不显示「收錄 0 位」；落定后为真实数（现库 570）。
7. 既有套件全绿（除已知基线红：`verify-ai-relay` F2）。
