#### 3.26.3 「下載高清原圖」的口径（**原 TIFF 字节直出**）

- **⇒ 明文七条（可机械判定）**：**① 产物 ＝ 存储件的原 TIFF 字节**（**＝ 单页 8bit Deflate TIFF；§3.22.1 四条 ＋ §3.25.2「单页」一项，原文一字未改**）；**② mime 按字节如实记 `image/tiff`**（**沿用 §3.12.10(b) 与 J-10「不采信自称值」；两处原文一字未改**）；**③ 不加水印**（**Kevin 四答第 ③ 条逐字「不对，是 TIFF，不加水印」**）；**④ 不经 TileSplicer**（**沿 §2.1 原文 44 ② 与 §3.24.3 ②；原文一字未改**）；**⑤ 零转码 / 零重编码**（**不得把原字节解了再编、不得改质量参数、不得改容器、不得重压 —— ⇒ byte-verbatim**）；**⑥ 全分辨率**（**不得缩放、不得裁剪**；**沿 §3.24.7 ④ 的「全分辨率」半个口径，原文一字未改**）；**⑦ 读路径零副作用**（**不得在直出时改写存储件 / 元数据 —— 与 §10.21 AC-158 / AC-167 同族，该两处原文一字未改**）。

- **⇒ 明文（与「防泄露」的关系，一条）**：**本面下发原字节**不构成防泄露判负面****（**⇒ ★ 见 §3.26.5 第九条；不得被描述为风险 / 泄露**）。

#### 3.26.4 下载件的**判据三件**（可机械判定）

- **⇒ 判据三件（缺一即判负）**：**① `sha256` ≡ 存储件 `sha256`**（**逐字节取证：两侧各给 `sha256` 原始输出 ＋ 文件字节数**）；**② 字节长度一致**（**下载件 `bytes` ≡ 存储件 `bytes`**）；**③ 魔数合法**（**前 4 字节为 `II*\0`（`49 49 2A 00`，小端）或 `MM\0*`（`4D 4D 00 2A`，大端）**）。
- **⇒ 明文四条（判读纪律）**：**① 三件必须**同时**给出**（**不得只给 `sha256` 而缺长度 / 魔数，也不得只给魔数而不比 `sha256`**）；**② `sha256` 的比对对象 ＝ **存储件**（**权威面；不得以「前端缓存件」或「展示件」替代比对对象**）；**③ 魔数判定**不得采信自称值****（**按字节判 —— 与 AC-141 同族，该行原文一字未改**）；**④ 面别限定**：**本三件只适用于显式索取面**（**隐式面不得据此要求任何字节比对 —— 隐式面根本不下发原字节**）。
- **⇒ 明文（反向误判封堵，三条）**：**（a）不得据「下载件与存储件的 mime 自称值不一致」判负**（**判 byte-verbatim 只看字节；mime 须按字节如实、不自证也不算功绩**）；**（b）不得据「下载件可被二次打开 / 可解析」判负**（**TIFF 能被解析恰为正常容器；不得据此要求改回 WebP**）；**（c）不得据「下载件体积较大」判负**（**原字节体积由容器与内容决定；本版不改任何上限数值**）。
- **判据落位**：**§10.24 AC-212**（判据三件）＋ **AC-214**（mime）。
