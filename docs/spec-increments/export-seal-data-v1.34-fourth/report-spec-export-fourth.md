## 2. S2：嵌图尺寸口径（新裁定）

### 2.1 裁定逐字

**导出嵌图取展示档原生像素、不额外降采样；仅当单边 > 1600 px 才降采样。** **理由逐字**：**Kevin 需求原话「各高清图片」＋ `R-EX3` 选定展示档 ⇒ 不得以「省体量」为由将 480 px 写进实现**（**「旧实现初值 480 已按本裁定改正」＝ 派单件转述的来源标注；本包未复跑实现、不声称当前形态**）。

### 2.2 明文五条（落位 ＝ §3.34.4 追加注（v1.34 第四包））

1. **尺寸真源 ＝ 展示档整图的原生像素**；
2. **不额外降采样**（**除第 3 条外一律不得再降 —— 尤不得以「产物太大」「写表慢」「Excel 体积」为由降**）；
3. **单边 > 1600 px ⇒ 允许降采样**（**形态 ＝ 等比缩放、保持长宽比、单边落至 ≤ 1600 px；不得裁切、不得变形、不得二次有损压缩后再转 PNG**）；
4. **与三类排除的关系 ＝ 不变**（**缩略图 / 切分块原样 / 原图 TIFF 一律不得作为嵌入件**；**明文：不得把「单边 > 1600 px 才降采样」读作「可以用缩略图代替」**）；
5. **判据面改读**：**§10.32 `AC-307` 判据 ② 读为「单边 ≤ 1600 px 时 ＝ 与展示档原生像素同尺寸同内容；单边 > 1600 px 时 ＝ 等比缩放至单边 ≤ 1600 px、比例不变、内容一致」**。

**⇒ 双向封堵（两条须齐备）**：**（i）不得据「嵌入件尺寸 ≠ 展示档原生尺寸」判负**（**命中 1600 px 例外者**）；**（ii）不得据「以 480 px 一类低尺寸嵌入」判通过**（**未超 1600 px 而擅自降采样 ⇒ 判负**）。

### 2.3 与体量的关系（落位 ＝ §3.34.10 追加注（v1.34 第四包））

**本包嵌图尺寸口径**不构成**体量上限** —— **体量仍不设硬上限 ✓**（**`W-40` 结案（`R-WX3`）原文一字未改**）；**① 不得把「单边 1600 px 的降采样门」读作产物体积上限**（**亦不得据此要求另设限额**）；**② 不得据「按原生像素嵌入后产物变大」判负**（**失败仍按 `R-EX9` 整体取消、零半成品文件**）。
