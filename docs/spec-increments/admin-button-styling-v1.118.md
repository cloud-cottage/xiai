## §3.94 管理员专属按钮的视觉区分（拟定）

### 3.94.1 口径

管理员权限才可见的按钮，**必须与普通用户可见的普通按钮从样式上区分开**，区分手段为**形状差异**，不是颜色差异：

1. **虚线边框**（与普通按钮的实线 / 无边框形成线型差异）；
2. **右上角锁形角标**（几何符号，非色彩）；
3. **悬停提示「僅管理員可見」**（`title` 与 `aria-label` 至少各一处）。

**禁令**：不得**只靠颜色**区分（色觉障碍用户须仍可辨）；不得以 `visibility` / `display` 隐藏作为「区分」手段（隐藏态元素脱离无障碍树，与 §3.93.3 行尾【勘誤】同口径）。

### 3.94.2 单点约束

- 样式一律落在**单一样式类**（现实现名 `.btn--admin`）与**单一角标组件**（现实现名 `AdminBadge`）上；**禁止逐处内联样式**、禁止每处手写一份锁标。
- 角标**绝对定位**于按钮右上角（可出界），**不得改变按钮盒模型**（宽高 / 内边距 / 圆角逐像素不变）；`pointer-events: none`（不侵占可点区域）；`aria-hidden="true"`（语义由 `title` / `aria-label` 承担，读屏不得把图形念进按钮名）。
- 颜色一律取既有设计令牌，**不得引入颜色字面量**；描边用 `currentColor` 以跟随按钮文字色 ⇒ 多主题自适应。

### 3.94.3 适用范围

**加**：所有「`v-if` 门来自管理员判定」的按钮（管理员专属读写入口）。
**不加**：普通用户即可见的操作（勘誤 / 存入雲盤 / 下載高清原圖 / 清除本機資料 / 实物照片上传 等）。
**既有口径不变**：非管理员 / 游客打开页面时，管理员专属按钮**本就不渲染**（DOM 零命中）；「入口不可见」与「数据层拒绝越权写」仍是两条独立要求。

### 3.94.4 钩子面

本口径是**纯视觉要求**，**不得新增 `[data-admin-action]` 取值**（该族取值集合仍恰 12），不得改动任何既有钩子名与行为。

## §10.102 判据（拟定，7 条）

| AC | 判据 | 判负形态 |
|---|---|---|
| `AC-795` | 单一样式类存在且含 `border-style: dashed`；其 `:hover` 回 `border-style: solid` | 缺该类 / 线型为 `solid` / `hover` 无回实线 ⇒ 判负 |
| `AC-796` | 该类主规则内**零** `visibility` / `display` 声明 | 出现任一 ⇒ 判负（不得以隐藏冒充区分） |
| `AC-797` | 角标组件：绝对定位 ＋ `pointer-events: none` ＋ `aria-hidden="true"` ＋ 内联 SVG | 缺任一项 / 角标参与盒模型 ⇒ 判负 |
| `AC-798` | 每个带该类的按钮开标签均含「僅管理員可見」（`title` 或 `aria-label`） | 有一处缺 ⇒ 判负 |
| `AC-799` | 带该类按钮数 ＝ 角标实例数（成对出现），且**逐个点名**覆盖全部管理员门控（现 10 个 `can*` 门 ＋ 校验作者） | 不成对 / 有管理员门控未覆盖 ⇒ 判负 |
| `AC-800` | 普通用户按钮（勘誤 / 存入雲盤 / 下載高清原圖）**零**该类；普通权限门（`canClearLocal` / `canUpload`）后**零**该类 | 误加即判负 |
| `AC-801` | `[data-admin-action]` 全仓取值集合仍恰 12；样式段与角标样式段无颜色字面量 | 计数变化 / 出现 `#hex` `rgb()` `hsl()` ⇒ 判负 |

**判据实现**：`scripts/verify-admin-buttons.mjs`（26 条，A 段样式单点 / B 段应用面 / C 段同批的作者选择器 / D 段 5 点变异负对照）。
