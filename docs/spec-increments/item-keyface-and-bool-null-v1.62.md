## 2. ① 布爾字段 `null` 容忍（§3.59.7 追加注（v1.62）｜A 件）

**終審口徑（逐字）**：

- **`has_image` / `has_annotation` 的合法形態 ＝ 布爾 或 `null`（恰兩類）。**
- **`null` ＝ 源側未知 ⇒ 不拒收、不落 `false`、不歸一成布爾、不得當拒收理由。**
- **字符串 `"false"` / `"1"` / 數字 `1` 仍必拒 ＋ 零寫入**（沿既有 `AC-532` 判負；**本注不放寬**）。

**實測輸入（來源 ＝ 派單方轉述 feicui 側；時點 ＝ 2026-10-10（CST）；只作輸入登記）**：**feicui 就緒包 1742 行中恰 **1 行**（`source_item_id=2536`）為 `has_annotation: null`（源側未知）。**（**本包未復跑該包；不改寫源側任何字節。**）

**雙向封堵（兩條須齊備）**：

- **（a）不得據「值為 `null`」** 把任一合規實現判負 ✗（**含不得把 `has_image` / `has_annotation` 的 `null` 當拒收理由、不得要求把 `null` 落 `false` 或歸一成布爾**）。
- **（b）不得據本注把字符串 `"false"` / `"1"` / 數字 `1` 判通過** ✗（**仍必拒 ＋ 零寫入**）。

**與既有 AC 的關係（行內文字一字未改）**：本注為 **`AC-532` ③ 讀法的收窄**（收窄面恰限 `has_image` / `has_annotation` 兩字段的 `null`）；`AC-532` 的編號與行內文字一字未改，判讀以 §3.59.7 追加注（v1.62）＋ §10.59 表下注（v1.62 追加）為準。
