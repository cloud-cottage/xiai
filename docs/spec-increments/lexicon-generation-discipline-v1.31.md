#### 3.31.1 ① 一句口径与适用范围

- **一句口径（Kevin 2026-09-23 定）**：**任何对词表资产**内容**的修改**，**必须同时具备下列五件**（**（a）恒等检测**／**（b）双向对拍**／**（c）分档门不得产出 CJK 扩展 B+ 与 PUA**／**（d）改动面全量清单与逐条 before→after**／**（e）旧版存档**）。**五件齐备 ＝ 该次修改的**准入条件**；缺一 ⇒ 该次修改不得合入**。
- **适用范围（逐条点名，恰三处资产）**：
  - **（i）`src/utils/traditional.js`** —— **逐字表**（**s2t 单字表 ＋ 由 s2t 表取反得到的 t2s 单字层**）。
  - **（ii）`src/utils/traditional-phrases-s2t.js`** —— **词组表（简体 → 繁体）**。
  - **（iii）`src/utils/traditional-phrases-t2s.js`** —— **词组表（繁体 → 简体）**。
- **⇒ 明文三条**：
  - **①** **适用范围 ＝ 「资产**内容**」**（**表内键 / 值 / 成员集合的增删改**）；**只改注释 / 只改格式 / 只改导出名 ⇒ 不属本节的修改面**（**但仍受既有契约纪律约束 —— §1.3 第 11 条**）。
  - **②** **本节的五件是**生成纪律**（**对「怎么改」的约束**），**不是对「改成什么」的口径裁定** ⇒ **补键的范围 / 顺序仍需 Kevin 裁（见 §3.31.7）**。
  - **③** **本节不要求回溯整改**：**既有词表资产的历史生成过程不因本节而被判缺陷**；**不得据「历史生成未附五件」判任何合规实现负**。

#### 3.31.2 ①（a）恒等检测（五件之一）

- **口径**：**简体输入经 `t2s` 必须保持自身**（**即对任一「本身已是简体」的输入串，`t2s(x) === x`**）。
- **取证面**：**逐条给出被测载荷、原值、`t2s` 结果三元组**；**给作用域命中节点数**（**§3.30.6（a）判据纪律同等适用**）。
- **⇒ 明文**：**恒等检测未做 ⇒ 该次修改不得合入**；**反之，恒等检测通过不构成本次修改「正确」的充分条件**（**（b）双向对拍仍须做**）。

#### 3.31.3 ①（b）双向对拍（五件之一；三面须齐备）

- **（b-1）`s2t` 面零漂移**：**改动前后，同一载荷集上的 `s2t` 结果必须逐条一致（零漂移）**。
- **（b-2）`t2s` 面变化逐条归因**：**`t2s` 面**允许**变化**（**这正是改动目的**），**但每一处变化必须逐条归因到**本次改动的具体改动项**。
- **（b-3）`unexplain = 0`**：**未能归因的变化条数必须为 0**（**`unexplain = 0` 为硬条件**）；**`unexplain > 0` ⇒ 该次修改不得合入**。
- **⇒ 明文**：**读数必须标面别**（**`s2t` 面 / `t2s` 面 / 词组面**）；**缺面别标注的对拍读数不得作判据证据**（**与 §3.27.2 的两把尺子不互计同源**）。

#### 3.31.4 ①（c）分档门不得产出 CJK 扩展 B+ 与 PUA（五件之一）

- **口径**：**任何词表资产的生成结果**（**逐字表与两张词组表的键与值**）**一律不得产出**：
  - **CJK 扩展 B 及以上（`U+20000` 及以后）**；
  - **PUA（私用区：`U+E000`–`U+F8FF` 与 `U+F0000` 及以上）**。
- **⇒ 与 §3.30 的关系**：**本节（c）与 §3.30.2 的「禁用档永不作为反查结果」同向、不同面** —— **§3.30.2 管**反查建法（档 2 永不输出）**；**本节（c）管**生成结果面**（**不论经哪条路径产出，结果里都不许出现这两类码位**）。**两条并行、互不替代**。
- **⇒ 明文**：**分档门被绕过（结果里出现扩展 B+ 或 PUA）⇒ 该次修改不得合入**；**不得以「该码位只在中间态出现、最终会覆盖」抗辩**（**判据只看最终生成结果**）。

#### 3.31.5 ①（d）改动面全量清单与逐条 before→after（五件之一）

- **口径**：**每次修改必须给出**全量**清单**（**改动面全量清单**）**＋ 每一条的**改动前 → 改动后**（**before → after**）**逐条对照**。
- **⇒ 明文**：**「全量」＝ 不抽样、不省略、不合并同类项**（**例：一次改 81 条 ⇒ 清单须 81 行，不得写成「等 81 条」**）；**未给全量清单 ⇒ 该次修改不得合入**。
