## §3.95 首页页头库存储量（新增）

1. **位置与形态**：`璽印匯類` 标题与说明文字之下、同一头部块内，独占一行；三段并列文本，繁体：
   `【璽印 N 枚】【印面 N 個】【圖像 N 張】`（千分位；量词逐字 `枚`／`個`／`張`）。
2. **数值语义 ＝ 库存储量**（集合总行数）：`seals → xiai_seals`、`faces → xiai_faces`、`images → xiai_images`。
3. **与列表页「共 N 枚」不同尺**：后者为 `listSealCards.total`（只算有面章）；两处数字**允许不同**，
   不得为求一致而改写任一口径。
4. **失败不上屏 0**：读取失败 ⇒ **整行不渲染**；不得回退本机演示数、不得以 `0` 冒充。
5. **零写 · 匿名可读**：只发 `count()`，恒零写；无需登录。

## §10.103 验收条目（`AC-802` 〜 `AC-806`）

| 编号 | 判据 |
|---|---|
| `AC-802` | 首页页头在说明文字之后渲染一行三计数，文案逐字 `【璽印 N 枚】【印面 N 個】【圖像 N 張】`（繁体、方头括号、千分位） |
| `AC-803` | 三计数＝对应集合总行数（含零面章）；不得取 `listSealCards.total` 或任何已载入页的派生计数 |
| `AC-804` | 三计数读取失败（未配置云端 / 传输失败 / 回包 `ok:false`）⇒ **该行不渲染**；**判负面**：上屏 `0 枚`／回退演示数据 |
| `AC-805` | 服务端 `PUBLIC_OPS` 含 `catalogStats`（**恰 5 成员**），载荷**封闭**（带任意键 ⇒ `INVALID_VALUE` ＋零读），回包**恰 4 键** `{ok,seals,faces,images}`，全程**零写** |
| `AC-806` | `catalogStats` 三个 `count()` 并行发起（无因果依赖不得串行）；异常由信封层回 `STORAGE_UNAVAILABLE`，不得伪装 `FORBIDDEN` |
