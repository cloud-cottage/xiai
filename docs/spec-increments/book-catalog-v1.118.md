## §3.95 印譜匯觀（`book` 數據 ＋ 影像歸屬印譜）（擬定）

### 3.95.1 一句口徑與適用範圍

- **凍結六面**：① 新集合 `xiai_books` 及其**六字段 ＋ 審計面**；② 關係字段 `xiai_images.book_id`（單值、可空、**一對多**、可清空、**不做級聯刪除**）；③ 側欄【印譜匯觀】的位置、順序、glyph 與**僅管理員渲染**；④ 路由 `/books` 與**雙門**（前端零請求 ＋ 服務端管理員門）；⑤ 三個管理員 op（`createBook` / `listBooks` / `setImageBook`）的**封閉鍵面、回包鍵面、冪等規則、發號單點復用禁令、讀回比對禁令**；⑥ 可見性（**暫時只有管理員可見**）與**普通用戶零洩漏**。
- **適用範圍** ＝ §4.1（數據模型）／§8.1（路由表）／§8.3（左側菜單）／§3.56.2（側邊欄四項）／§3.88・§3.89（影像與面的分層）／§3.94（引用型作者）／§3.84（`ADMIN_OPS` 對拍）。
- **生效起點** ＝ 本版（v1.118）。**與既有條款衝突處一律以本節為準**，並以**追加注**承載「取代 / 收窄 §X 的…」，**被收窄處原文逐字保留、行內文字一字未改**。
- **本件不含**：落地方案、組件設計、腳本實跑讀數、任何「已上線 / 已驗收」結論（**落地歸實現單、驗收歸 Neng**）。

### 3.95.2 新集合 `xiai_books`（六字段 ＋ 審計面）

| 字段 | 類型 | 必填 | 口徑（逐字） |
| --- | --- | --- | --- |
| `id` | 字符串 | ✓ | **＝ `book_id`**，**五位純數字**（`'00001'`、`'00002'` …）；**系統發號、管理員不可改**；**遞增不重號** |
| `name` | 字符串 | ✓ | 書名。**簡體 / 繁體均可、不強制轉換**；**上屏原樣輸出，不跑 `s2t` / `t2s`** |
| `isbn` | 字符串 | 可空 | 空串 / `null` **均讀作「未著錄」**（兩態等價）；非空時**保留原樣**（**連字符不剝、不補位、不校驗位重算**） |
| `cip` | 字符串 | 可空 | 同上（空串 / `null` 等價；非空保留原樣） |
| `author_person_id` | 字符串 | ✓ | **引用型**：必須是 `xiai_persons` **已收錄印人**（**與勘誤作者同門**，沿 §3.94）；**上屏用 `persons.personName`**；**不得落自由文本、不得落人名快照** |
| `first_publish_year` | 整數 | 可空 | 首次出版年份；非空時**須為整數且 `1000` ≤ 值 ≤ 當年**（「當年」按服務端當日所屬年份判定）；越界／非整數 ⇒ 拒 |
| `created_by` / `created_at` / `updated_at` | — | — | **審計面，服務端寫**；**客戶端不可遞**（載荷出現此三鍵 ⇒ `INVALID_FIELD`） |

- **字段數守恆**：`xiai_books` 的**寫入面恰 5 鍵可遞**（`name` / `isbn` / `cip` / `author_person_id` / `first_publish_year`），**`id` 由服務端發號、不由載荷收**；**6 字段 ＋ 3 審計鍵 ＝ 行面 9 鍵**（本條只凍結「可遞 5 鍵、發號 1 鍵、審計 3 鍵」三分，**不新增「恰 N 鍵」的行面總數約束**）。
- **空值語義（硬）**：`isbn` / `cip` / `first_publish_year` **三者可空**；**空 ≠ 缺失必填**（不得因三者為空而拒建）；`name` / `author_person_id` **二者為必填門**，空串 / 純空白 / `null` **一律讀作缺失**（`MISSING_REQUIRED`）。
- **`name` 不做唯一性判定**（同名不同書合法，如重印／再版）；**唯一性只落在 `id`**（見 3.95.6 冪等條）。

### 3.95.3 關係字段 `xiai_images.book_id`（一對多、可清空、不級聯）

- 影像行（`xiai_images`）新增 **`book_id`**（字符串，**可空**）。
- **一對多（硬）**：**一張影像至多一本書** ⇒ **單值字符串，不是數組**；**同一影像掛第二本 ⇒ 替換為最新**（不雙值、不建第二行、不殘留舊值）。
- **覆蓋兩類影像（同一字段）**：**face 的圖片**（面行 `face_image_id` 指向的影像行）與**不指定 face 的整章圖片**（`stamp_id` 指向本章、且未被任何面行引用的影像行）—— 二者**都是 `xiai_images` 行**，故**一個字段覆蓋**；**不新增第二個關係字段、不改 §3.88 / §3.89 的面分層口徑**。
- **清空合法（硬）**：`book_id = null` ＝ 「**取消歸屬**」，**不是拒收項、不記為失敗**。
- **不做級聯刪除（硬）**：**本批 `book` 無刪除能力**（不提供 `deleteBook` / 批量刪除 / 軟刪旗標）；**影像被刪不影響 `book`**；**`book` 側變動不得寫入影像行**（除 `setImageBook` 顯式改 `book_id` 一鍵外）。
- **懸空口徑**：`setImageBook` 寫入前**必須校驗 `book_id` 指向的書存在**（見 3.95.6）；**存量行 `book_id` 缺鍵按「未歸屬」只讀兼容派生**（不遷移、不批量回填）。

### 3.95.4 側欄【印譜匯觀】：位置、glyph、僅管理員渲染

- **菜單項（逐字）**：`{ key: 'books', to: { name: 'books' }, glyph: '譜', label: '印譜匯觀' }`。
- **位置（硬）**：**位於【我的雲盤】之前** —— 沿現行四項次序（§3.56.2：① 璽印匯類 ② 印風匯覽 ③ 印家匯徵 ④ 我的雲盤）⇒ **管理員所見為五項，本項落第 4 位、【我的雲盤】順延為第 5 位**；**前 3 項 label 與順序逐字不動**（**不插隊、不改序**）。**非管理員所見仍恰四項**（**本項不渲染，其餘四項次序逐字不變**）。
- **glyph 紀律**：**單字 `譜`**（沿 §3.56.2 / §8.3 ③「一律單字」）；**不畫 SVG、不用多字、不用圖形**；**不得因「字典無此字形」改用圖片替代**。
- **僅管理員渲染（硬，三態齊備）**：**未登錄 / 普通用戶 ⇒ 該項 DOM 零命中**；**不得以 `disabled` 冒充**；**不得以 `visibility` / `display` / `opacity: 0` / 移出視口等 CSS 手段冒充**（**隱藏態元素脫離無障礙樹，與 §3.93.3 行尾【勘誤】、§3.94.1 禁令同口徑**）；**不得以空 `href` / `pointer-events: none` 的「死項」冒充不渲染**。
- **與 §8.3 / §3.56.2 既有判負形態的關係（收窄，不改原文）**：上兩處的「**菜單項數 ≠ 4**」自本版起**只對未登錄 / 普通用戶生效**；「**以新增菜單項承載管理員的編輯能力**」的禁令**適用面 ＝ §2.1 原文 7 所稱三項編輯按鈕能力**（上傳印章 / 編輯固定屬性 / 勘誤採納駁回）—— **本項不承載該三項能力**（它是 `book` 數據與圖↔書關係的管理面），**故不在該禁令射程內**；**但本項不得被當作「把三項按鈕搬進菜單」的先例**（**反向封堵**）。

### 3.95.5 路由 `/books`：零數據請求 ＋ 雙門

- **路由（逐字）**：`/books`，`name: 'books'`，`meta.title: '印譜匯觀'`（**繁體、逐字**）；視圖落點 `src/views/BookIndexView.vue`（**只定名、不定實現**）。
- **`requiresAuth`**：**本條不代裁**（管理員門由**頁內 ＋ 服務端**承擔；沿「只凍結已給口徑、不自行發明」紀律）。**但無論該旗標取何值，下述兩門齊備即為合規**。
- **門一（前端，零請求硬）**：**非管理員 / 未登錄直接訪問 `/books`**（深鏈、頁內刷新、前進後退均算）⇒ **頁面顯示無權限提示**（**文案自定，不得靜默空白**），且**零 `book` 數據請求**（`listBooks` / `createBook` / `setImageBook` 調用數 **＝ 0**；**不得「先取後藏」、不得「取回再以 `v-if` 隱藏」**）。**判負形態 ＝ 任意一次 `book` 相關請求發生在權限判定之前或並行**。
- **門二（服務端，硬）**：三個 `book` op **一律走既有管理員門 `adminWhitelistDenial`**（缺 env / 非白名單 ⇒ **結構化拒 ＋ 零讀零寫**，與既有各管理員 op 同型）；**該門判定早於任何讀**（**先門後讀，不得門後讀**）。
- **雙門獨立（硬）**：**「前端不渲染 / 零請求」與「服務端拒絕越權讀寫」是兩條獨立要求，缺一即判負**（沿 §3.6 / §3.7 / §6.2「入口不可見」＋「數據層拒絕」兩條並列之既有紀律）。
- **路由集合**：§8.1 路由自本版起 **11 → 12 條**（**上表 7 行與各版表下注原文逐字未改**，計數由 §8.1 表下注（v1.118 追加）承載）；**兜底重定向 `/:pathMatch(.*)*` ⇒ 璽印匯類，形態與指向一字未改，不得被本條破壞**（沿 `AC-106` / `AC-503`）。

### 3.95.6 三個管理員 op：封閉鍵面、回包鍵面、冪等

**共通（三 op 全部適用，硬）**：**載荷一律封閉鍵面** —— **未知鍵 ⇒ `INVALID_FIELD`（不得靜默丟棄）**；**鍵面判定早於任何讀寫**；**只回結構化體**（成功 `ok: true`、失敗帶既有 `reason`，**`reason` 零新增字面值**，只用既有 `MISSING_REQUIRED` / `INVALID_VALUE` / `INVALID_FIELD`）；**零新增 `[data-admin-action]` 取值**（新前端鉤子一律 `data-action`，沿 v1.116 先例）。

| op | 載荷（封閉，逐鍵） | 回包（逐鍵） | 口徑 |
| --- | --- | --- | --- |
| `createBook` | **恰 5 鍵**：`name` / `isbn` / `cip` / `author_person_id` / `first_publish_year` | **恰 2 鍵**：`{ ok, book_id }` | `name` / `author_person_id` **必填**；`isbn` / `cip` / `first_publish_year` **可空**；`first_publish_year` 越界（< `1000` / > 當年 / 非整數）⇒ `INVALID_VALUE`；`author_person_id` **必須是已收錄印人**（沿 §3.54.x 作者校驗同門，讀人行走既有單點）；`book_id` **服務端發號**；**冪等**：同 `name` ＋ 同 `author_person_id` 已存在 ⇒ **回既有 `book_id`、不建第二行**（**不報錯、不覆寫既有行**） |
| `listBooks` | **恰 0 鍵**：`{}`（**出現任何鍵 ⇒ `INVALID_FIELD`**） | **恰 3 鍵**：`{ ok, books: [...], total }` | **管理員讀**；**按 `id` 升序**（字符串升序即五位定長數值序）；`total` ＝ 全量條數（**本 op 不分頁、不收 `limit` / `cursor`**；若日後分頁屬規範變更）；`books` 元素**只回 9 鍵行面**（6 字段 ＋ 3 審計鍵），**不得夾帶影像行 / 人名快照** |
| `setImageBook` | **恰 2 鍵**：`image_id` / `book_id`（`book_id` 傳 `null` ＝ **取消**） | **恰 3 鍵**：`{ ok, image_id, book_id }` | **先驗兩事**：① 影像行存在（不存在 ⇒ 拒，**不得新建行**）；② `book_id` 非 `null` 時**其所指書存在**（不存在 ⇒ 拒，**不得寫懸空值**）；**寫後必讀回比對**（見 3.95.7）；**只改 `book_id` 一鍵**，不得順手改 `kind` / `stamp_id` / `face_image_id` / `is_primary` / 時間戳以外的任何鍵 |

- **三 op 的共同拒絕面（判負形態）**：多一鍵 / 少一鍵；未知鍵被靜默丟棄；門後或讀後才做鍵面判定；`createBook` 由載荷採信 `id` / `book_id` / `created_*` / `updated_*`；`setImageBook` 對不存在影像或不存在書仍寫；`listBooks` 對非管理員回了數據 ⇒ **逐項判負**。

### 3.95.7 發號單點復用禁令 ＋ 讀回比對禁令

- **發號單點（硬）**：`book_id` **一律復用既有發號單點**（`issueCodeNumberAvoiding(kind, isTaken)` 形態，`isTaken` 按 `xiai_books.id` 查重），**避讓全庫已佔號**；**禁止隨機 id / 時間戳 id / 客戶端發號 / 讀 `max + 1` 拼接不入單點**；**禁止另立第二套發號器**（沿 §3.88.4「必復用既有單點」同口徑）。
- **五位純數字（硬）**：`id` **恰 5 位數字、前導零補齊**（`00001`）；**到 `99999` 後的行為屬規範變更、本版不裁**（**不得據「六位數」判通過、亦不得據「溢出未定」判負**）。
- **讀回比對（硬，禁令）**：`setImageBook` **不得以 `updated >= 1` / 「無異常」/ 「請求 200」判定成功** ⇒ **寫後必須讀回該影像行，比對 `book_id` 值與本次請求值逐字相等**（含雙方皆為 `null` 的「清空成功」）；**讀回不一致 ⇒ 回失敗（不得回 `ok: true`）**；**前端不得在失敗時保留假狀態**（**不得先把下拉顯示成新值再等回包**；失敗須回滾顯示並給可見反饋）。

### 3.95.8 可見性：暫時只有管理員可見 ＋ 普通用戶零洩漏

- **範圍（Kevin C 條原文口徑）**：**`book` 數據與圖↔書關係，暫時只有管理員可見**。三面齊備：
  1. **菜單**：本項對非管理員 / 未登錄**不渲染**（3.95.4）；
  2. **頁面**：`/books` 對非管理員**不可達**（無權限提示 ＋ 零請求，3.95.5）；
  3. **詳情頁**：「所屬印譜」下拉（face 圖旁與整章圖旁**兩處**）**僅管理員可見**；非管理員側 **DOM 零命中**（**同 3.95.4 三態紀律：不得 `disabled` / CSS 隱藏冒充**）。
- **DTO 零洩漏（硬）**：**`book_id` 不得出現在任何普通用戶可見的 DTO / 卡片 / 列表 / 詳情 / `listSealCards` 行面 / `q` 檢索結果**（**卡片 DTO 仍恰 14 鍵 —— 沿 §3.81.4，本版不新增第 15 鍵**）；**不得以「管理員多一鍵、普通用戶少一鍵」的雙形態回包代替「普通用戶零洩漏」**（**判負 ＝ 同一個 op 依身份返回不同鍵集**；**允許的做法是另立管理員面 op，如 `listBooks`**）。
