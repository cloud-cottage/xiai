## 2. 编码（已穷举验证，0 失败）

- 字母表 **22 位**逐字：`A B C D E F G H J K M N P Q R S T V W X Y Z`（＝ Crockford base32 去掉数字后的字母子集；**不含 I L O U** ⇒ 与 0/1 天然不混淆）。
- **sid**：`n ∈ [1, 5153632]` ⇒ 定长 5 位 base-22，`1 → AAAAB`、`22 → AAABA`、`5153632 → ZZZZZ`。
- **fid**：`n ∈ [1, 100000000]` ⇒ 十进制 8 位零填充，`1 → 00000001`。
- **双向**：encode 为基数展开，decode 为基数累加 + 号域越界即拒。**双向均为纯函数、零表、O(1)**；`decode(encode(n)) === n` 已在 n = 1..5,153,632 全量验过。
- **容量悬崖（须规范登记）**：sid 上限 5,153,632（超限**结构化拒绝**，不得静默回绕）。升级路径 = 6 位（22⁶ = 113,623,104），**本轮不做**。
- **禁用派生**：**不得**由既有 `XA` + 9 位印章编号序号派生 sid（9 位容量 10⁹ 与 5.15M 差两个数量级）。

## 3. 字段面与号源

| 实体 | 新键 | 类型 / 值域 | 分配时机 |
| --- | --- | --- | --- |
| 印章 | `seal_no` | 整数 ≥ 1（自增号，权威） | 云函数发号（新建 / 导入采纳） |
| 印章 | `sid` | `/^[A-HJ-KM-NP-TV-Z]{5}$/`（恰 22 字母，实测展开 ＝ `ABCDEFGHJKMNPQRSTVWXYZ`） | **由 `seal_no` 重算，不独立分配** |
| 印面 | `face_no` | 整数 ≥ 1（自增号，权威） | 同上 |
| 印面 | `fid` | `/^\d{8}$/` | 由 `face_no` 重算 |

- **号源集合**：新增 `xiai_counters`（`_id` ∈ `seal` / `face`，文档含 `seq`），云函数内**原子自增**发号 ⇒ **集合清单 23 → 24 项**（须同步 §3.33.3 + `AC-293` + 各套件写死的计数断言，**期望值按严格等值亲改，禁删断言**）。
- **`xiai_counters` 不入云读面**：它是**服务端专用**集合（客户端零读），**不得加进 `CLOUD_COLLECTIONS` / `CLOUD_COLLECTION_KEYS` / `CLOUD_KEY_OF_LOCAL`**（加了等于把号源暴露给匿名读面）。可达性断言（`AC-522`）只覆盖云读面键，不受影响。
- **服务端重算校验**：载荷里的 `sid` / `fid` **一律不采信**；服务端按 `no` 重算后比对，不符 ⇒ 结构化拒绝、零写入。客户端可自算用于即时回显，但**落盘值恒由服务端产出**。
- **旧编号并存不改**：`XA000000001`（印章 `stamp_id`）、`fc-<印章序号>-<f|e><n>`（印面 `_id`）**逐字保留、不重编号、不参与新号递增**。

## 4. 回填（R-3）

- **一次性幂等管理员 op**（`migrateCodeNumbers` 同型）：`dry_run` 缺省 `true`，须吐 `scanned` / `assigned` / `skipped` / `samples`；重放 ⇒ **`assigned: 0` 且逐行前后逐字节不变**。
- **按既有稳定顺序发号**（印章：`stamp_id` 序号升序；印面：印章号 ＋ 同类序号），**只补缺键行**（`{seal_no: {$exists: false}}`），**不改任何既有值**。
- **回填不改写旧编号**；行上并存 `stamp_id`（旧）＋ `seal_no`/`sid`（新）。
- **本 op 不新增 `[data-admin-action]` 取值**（无界面按钮，纯 op 调用）；去重集合仍为规范现值。

## 5. 搜索面（R-4）

- 入口：广场页既有 `q` 关键词搜索之外**新增识别编码入口**（一个搜索框）。
- **自动判型**：首字符 ∈ 22 字母 ⇒ 5 格字母键盘（每格单字母、自动上移、自动大写）；首字符为数字 ⇒ 8 格数字键盘。
- **非法字符一律拒**：`0/1/I/L/O/U` 及所有非字母、非数字字符**就地拒绝**并提示（**不做自动纠错映射**——字符集本就不含这些字母，无映射可做）。
- **精确命中**：decode ⇒ 按 `no` 精确查；**查无回「查無此印」**，**不得回落模糊匹配、不得回落到 `q` 关键词路径**。
- **上屏文案一律繁體**（`s2t(x) === x`）；**零「切分」措辞**。

## 6. 判据面（供规范侧参考边界，具体 AC 由 Jing 定）

1. 编码器**恰一处纯函数**，前端 / 云函数双副本**逐字相等**（机械断言，同 `MARKABLE_FIELDS` 纪律）。
2. 双射：`decode(encode(n)) === n` 对边界与抽样号成立；越界（0 / 5,153,633 / 10⁸）**结构化拒绝**。
3. 服务端重算：伪造 `sid` ⇒ 拒绝 + **零写入**；合法 ⇒ 落盘 `sid` ≡ 按 `seal_no` 重算值。
4. 并发发号：N 路并发新建 ⇒ **无重号、无空洞回填、`seq` 单调**。
5. 回填幂等：重放 `assigned: 0` ＋ 逐行前后快照逐字节不变。
6. 旧编号零改动：`XA000000001` 与 `fc-…` 行前后逐字相等。
7. 搜索判型：字母首字符 ⇒ 5 格；数字首字符 ⇒ 8 格；非法字符拒；查无 ⇒ 明确空态、零模糊回落。
8. 计数面：集合 24 项；`[data-admin-action]` 不新增；`reason` 字面值**零新增**（复用 `INVALID_VALUE` / `INVALID_FIELD` / `NOT_FOUND`）。
