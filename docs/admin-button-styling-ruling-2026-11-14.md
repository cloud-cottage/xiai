# 裁定：管理员专属按钮的样式区分（虚线边框 ＋ 锁形角标）

- 状态：**已裁定**（Kevin 2026-11-14 CST，变体 A）
- 性质：非规范。供实现 / 规范 / 质检单作唯一口径真源。

## 一、口径

管理员权限才可见的按钮，与普通用户可见的普通按钮，**从样式上区分开**：

1. **虚线边框**（与普通按钮的实线/无边框形成形状差异）。
2. **右上角一枚小锁形角标**（不动布局，绝对定位）。
3. **悬停提示「僅管理員可見」**（`title` ＋ `aria-label` 后缀）。

## 二、现状（实测）

- 详情页有 **12 个**管理员门控按钮（`canEditFixed` / `canReplaceFaceImage` / `canAiEnhanceFace` / `canSetBaseFaceOn` / `canDeleteFaceImage` / `canEditSealAttrs` / `canDeleteSeal` / `canAddSealFace` / `canExportSeal` / `canDeleteWholeSealImage` / `canUpload` / `canSubmitAuthorVerify` 等门）。
- 它们与普通按钮**共用同一套** `btn btn--ghost` ⇒ 视觉上完全一致（例：「編輯固定屬性」与「勘誤」无法从外观区分）。
- 现有样式类只有 `.btn--ghost`（36 处）与 `.btn--primary`（8 处），**没有**管理员变体。

## 三、实现契约

- **单点样式类 `.btn--admin`**（外加角标元素），**不得每处手写内联样式**：
  - `border-style: dashed`（保留既有 border 宽度与圆角，只改线型）；
  - 角标：`position:absolute` 于右上角（约 `-4px` 出界），内容为**内联 SVG 小锁**（约 10–12px），`aria-hidden="true"`（语义由 `title` 承担）；
  - 悬停时恢复为实线边框（给「可点」的反馈），角标保持不变。
- **可访问性（硬）**：区分**不得只靠颜色**（虚线是形状差异，锁标是形状符号）；`title` 与 `aria-label` 都必须追加「僅管理員可見」；角标不得影响布局尺寸（绝对定位，父元素 `position: relative`）。
- **应用范围（本批）**：印章详情页 + 新增印面/上传印章等**同源管理员按钮**；判定以「该按钮的 `v-if` 门来自管理员判定」为准，逐个列出并核对，**普通用户按钮（勘誤 / 存入雲盤 / 下載高清原圖 / 加面等普通操作）一律不得加**。
- **不得新增 `[data-admin-action]` 取值**（该族仍恰 12 值）；新样式不改变任何钩子与行为。

## 四、验收

1. 详情页每个管理员门控按钮都带 `.btn--admin` 且渲染出锁形角标；`title` / `aria-label` 含「僅管理員可見」。
2. 普通用户按钮（勘誤等）**不带**该类、无角标；以普通用户身份（未登录/非白名单）打开页面时，管理员按钮本就不渲染（DOM 零命中，既有口径不变）。
3. 布局不因角标位移（对比加样式前后的按钮盒模型尺寸一致）。
4. `[data-admin-action]` 仍恰 12 值；`data-action` 钩子集合未变。
5. 对比度：虚线边框与锁标在浅/深色下均可见（沿用既有 token，不引入新颜色字面量语义）。
