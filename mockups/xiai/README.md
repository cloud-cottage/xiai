## 2. 一句话特征

- **v1 宣纸朱印**——米白宣纸底、朱红为主、墨黑字，触感温润、书卷气最足；印章以「朱文红框」为主视觉。
- **v2 墨底金线**——近黑墨底、金色细线描边、金作重点，暗红只作点缀，碑帖拓本般的沉静感，夜里看最舒服。
- **v3 拓片灰金**——拓片灰底（比 v2 明显亮，属中间调）配浅拓纸卡面，金线 + 暗红并用，像把拓片裱在灰板上。

三版底色实测相对亮度：v1 `0.8102`（浅）／ v2 `0.0062`（近黑）／ v3 `0.0975`（中间调灰），**v2 与 v3 不是同一档深色**（底板对比 2.62:1，肉眼可辨）。

## 4. 色值 token 化与自检结果

- **零外链实测**：`http`／`https`／`src=`／`@import`／`<link`／`url(`／`fetch(`／`XMLHttpRequest` 在三份文件中命中数**全部为 0**；`<link>`、`<img>`、`<script src>` 标签数 0。
- **色值集中**：十六进制色值只出现在每个文件顶部的 `:root` 令牌块内（v1/v2 各 18 处、v3 16 处），**规则体内 0 处**；文件里其余的 `#` 共 6 处，全部是 `href="#main"` 锚点。
- **对比度实测 52 组**（26 组非文本图形 ≥3:1、26 组文本 ≥4.5:1），三版**全部通过**：
  - v1：非文本最低 `3.04:1`（提示条描边 / 提示条底），文本最低 `4.96:1`
  - v2：非文本最低 `3.08:1`（分隔线 / 面板底），文本最低 `4.69:1`
  - v3：非文本最低 `3.22:1`（印面边框 / 印面底），文本最低 `4.53:1`
  - 考核范围含：筛选 chip 轮廓、卡片轮廓、分隔线、页头图标 / 铃铛 / 徽标、侧栏激活标记与计数徽标、按钮与遮罩按钮轮廓、印面笔画与边框、标签与提示条描边。

## 5. 实现落地时需要替换哪些 token

本稿令牌名与工程 `src/styles/tokens.css` 的语义**同名同构**（`--c-*` 基底 + `--slot-*` 槽位，按 `data-theme` 切换）。落地时按下表把选定稿的 `:root` 值整体搬进对应主题块即可，**组件不必改**。

### 5.1 需要新增的基底令牌（工程目前没有，三稿都在用）

| 令牌 | 用途 |
| --- | --- |
| `--c-on-brand` | 主色块上的文字（按钮 / 徽标 / 头像 / 计数徽标共用） |
| `--c-text-on-bg` / `--c-text-on-bg-muted` | 直接压在页面底板上的文字 / 次级文字（页头之外区域） |
| `--c-gold-on-bg` | 底板上的金（侧栏小标题、说明卡标题、侧栏激活标记） |
| `--c-line-on-bg` / `--c-line-on-bg-strong` | 底板上的分隔线 / 控件轮廓（次按钮描边） |

### 5.2 与工程现有主题的差异（同名令牌，值不同）

若选 **v1 → theme a**（10 个值不同）：

| 令牌 | 工程现值 | 本稿 v1 | 原因 |
| --- | --- | --- | --- |
| `--c-bg` | `#f4efe4` | `#efe8d8` | 底板压深一档，与卡面拉开层次 |
| `--c-surface` | `#fbf8f1` | `#fdfaf3` | 卡面提亮，卡片浮起来 |
| `--c-surface-sunken` | `#ece5d7` | `#ece4d3` | 略偏中性，避免与底板撞色 |
| `--c-text` / `--c-text-muted` | `#1b1815` / `#5d5348` | `#191512` / `#574d40` | 微调 |
| `--c-line` | `rgba(27,24,21,.18)` | `rgba(25,21,18,.52)` | **关键**：.18 压在卡面上只有 1.45:1，分隔线「看不见」；.52 实测 3.62:1 |
| `--c-line-strong` | `rgba(27,24,21,.46)` | `rgba(25,21,18,.78)` | 控件轮廓统一提到 ≥3:1 |
| `--c-brand-strong` | `#7d1c12` | `#7c1a10` | 微调 |
| `--c-gold` / `--c-gold-strong` | `#8a6a1f` / `#6d5315` | `#7d5f16` / `#5f470f` | 浅底上积分数字更实 |

若选 **v2 → theme b**（8 个值不同）：`--c-line` `rgba(201,162,74,.22)→.55`、`--c-line-strong` `.55→.88`（同上原因，金线要看得见）、`--c-brand` `#a8352a→#b23a2c`、`--c-brand-strong` `#c4553f→#cf5c44`、`--c-gold-strong` `#dcb968→#e0bd6d`、`--c-text-muted` `#a99d88→#b3a794`（次级文字提到 4.5:1 以上）、以及 `--c-brand-soft`/`--c-gold-soft` 数值微调。

> **v2 的一个硬约束**：选中 chip / 未读徽标这类「图形块」不能用工程现值的 `#a8352a`——压在筛选底 `#1a1714` 上实测只有 **2.73:1**（低于 3:1，控件会糊掉）。本稿改用 `--c-brand-strong` `#cf5c44`（实测 **4.30:1**），暗红只留在印面边框与文字上。

若选 **v3 → theme c**（12 个值不同，**建议整块替换**）：工程 theme c 的底板是 `#383834`（相对亮度 0.039），本质仍是「第二个深色主题」，与 theme b 区分度不够；本稿 v3 把底板提到 `#5b584e`（亮度 0.0975，真正的中间调），并把卡面翻成浅拓纸 `#e9e3d3`、文字转为深墨 `#221f19`，金与暗红都要换成「浅面上用」的深值（`--c-gold #8a6a1f`、`--c-gold-strong #6d5315`）。**注意方向相反**：`--c-text` 由浅转深、`--c-line*` 由浅色描边改为深色描边。若只想保留原深色方案，则 v3 与 v2 会撞车，应改选 v1 或 v2。

## 6. 打开与验收

- 双击任一文件即可（`file://` 打开，不发任何网络请求）。
- 建议同时开三个标签页来回切，重点看三处：① 卡片悬停时浮出的两个操作是否够醒目；② 筛选条里未选中的 chip 轮廓是否看得见；③ 页面底板整体气质（纸感 / 碑感 / 拓片感）。
- 本单只产视觉稿，**未改动工程任何其它文件**（`src/**`、`docs/**`、`feicui/**`、`web/**`、`ctrl/**` 均未触碰），未启停任何进程，未占用端口。
