兆级玺印数字引擎

以结构化玺印数据基座，赋能文博展陈应用。面向博物馆、古籍与篆刻研究机构的玺印结构化数字服务平台：收录十万方历代玺印，配套印面、边款多视角高清影像与完整著录元数据，通过标准化 REST API 对外提供检索与图像调用能力，支撑学术研究、线上展厅、数字化典藏项目。

资源总览

体量 · 著录 · 数据库底座

资源体量

玺印体量：100,000 方历代玺印，远期迈向兆级规模愿景。

影像素材：每方玺印配套 2–4 组影像（印面、边款特写），合计约 40 万张影像。

结构化著录

印名、释文、朝代、材质、玺印类型；类型支持姓名印、闲章、吉语印、官印、鉴藏印。

多维度分类检索，适配学术著录规范。

数据库底座

PostgreSQL，支持古文释文、异体字检索。

内置强数据校验，保障文博著录规范。

归档母版

  • TIFF G4（CCITT Group4），无损压缩，文博标准归档格式；仅用于底层存档，不对外分发。
  • 朱文两色玺印采用 TIFF 调色板格式。

在线预览

  • 预生成无损 WebP 优先，PNG 索引 2 色兜底；HTTP 内容协商自动适配客户端浏览器，原生支持透明底。

图像规格

  • 2 cm 见方，400PPI 双色二值图像，印文线条锐利纯净，无多余灰度噪点，满足学术研究与数字展陈标准。

性能优势

  • 高清预览图像仅数 KB，CDN 全球分发；批量一次性加载百方玺印，瞬时完成渲染，流量开销极低。

API 查询服务

标准化 REST 接口 · 机构包量套餐

多维检索

关键词、朝代、材质、玺印类型多条件联合筛选；支持释文近似相似度检索。

GET /v1/seals?dynasty=&material=&type=

图像资源输出

返回 WebP / PNG 高清预览图访问地址，归档 TIFF 母本隔离保护，保障原始档案安全。

GET /v1/seals/{id}/images

接入与计费

机构包量套餐：年度平台授权与运维服务费（年费）+ 月度包量 API 调用 + 超量按次 + 高清原图按张。典型场景：每月 200 次查阅会话，单次会话浏览 100 方玺印，调取 10 张高清原图；先用月包量，后扣充值余额，包量不跨月结转。
