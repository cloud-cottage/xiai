## 四、已知未实测项（诚实清单，未测 ≠ 有问题）

以下项目**本轮没有实际验证**，不构成任何通过声明（沿用上轮结论，本轮新增项已标注）：

### 顺带发现、**未修改**的产品级缺陷（只列不改，交由派单决定）

1. **失败 / 超时后主按钮被置灰，重试入口只在订单表**：`updatePayView()` 在最新订单为 `FAILED` / `EXPIRED` 时把「去支付」设为 `disabled`，恢复路径只有计费页订单表里的「重新下单（新订单号）」。逻辑上符合「重试不复用旧订单号」，但同一屏里没有就地提示新用户去哪儿点，可用性上有断层。
2. **订单号格式与规范 §数据字典不一致**：页面用 `YS-YYYYMMDD-NNNN`，规范 `orderId` 定义为 `RO` + YYYYMMDD + 6 位序列（如 `RO20260918000001`）。本轮未改（属口径变更，需派单）。
3. **V1/V2 的朱文印透明底仍用渐变棋盘纹**：与「全站零渐变」的表述存在解释空间（见第二节注）。
4. **演示时钟与演示数据不同日**：假支付入账现在取**本机真实时钟**（本轮实测为 `2026-09-18 23:02`），而示例用量 / 流水数据冻结在 `2026-09-19`；因此新入账行显示的时间会早于既有示例行（新行仍排在表首）。生产实现应以服务端时间为准。
5. **入账时间戳为分钟粒度**：同一分钟内连点两次「模拟支付成功」，两行的 `cst` 文本相同（但 `关联单号` 递增、余额快照不同）。若需逐次可区分，需与规范统一秒级格式（本轮按「与其他流水格式一致」的要求保持 `YYYY-MM-DD HH:mm`）。
6. **`<input>` placeholder 对比度**：V3 的 placeholder 本轮已顺带提到 4.7:1（原 2.39:1）；V1/V2 的 placeholder（`#b3aea3` / 同族浅灰）本轮未调整也未审计，QA 上轮未列入缺陷。

   - ① 首页（营销）　② 注册 / 登录　③ 控制台概览（密钥管理区 + 用量明细区）　④ 计费规则（充值区 + 账单区）
3. 切换条支持键盘 ← → 方向键翻屏；站内文字链（「机构登录」「进入控制台」「查看计费规则」等 12 处 `data-goto`）均在本文件内跳屏或滚动定位。
4. 页内交互（子标签、环境切换、充值金额、密钥显示 / 复制、各类按钮）为**纯前端演示**：只弹提示、不改真实数据，未接后端的入口都会明确提示「演示环境…」。**例外**：导出 CSV 会真实下载一个本地生成的 `.csv` 文件（浏览器本地 Blob，无外部请求）。
5. 桌面优先：≥1200px 为设计目标宽度；768–1200px 收窄后重排（侧栏变横向、栅格降列、宽表横向滚动），800–1440px 区间实测零横向溢出。

## 六、每版设计取向

### V1 典藏宋韵
- 完全沿用官网 `index.html` 血统：宣纸底 `#f8f6f0` + 酒红 `#992222` + 宋体栈 + 1px 细线 + 4px 圆角、**无阴影**。
- 控制台与营销页同一套材质：宋体、细线表格、纸色侧栏、下划线块状标签，气质是「机构台账 / 档案著录」。
- 取舍：数据密度最低、图表最克制；适合「先要稳重、不惊动甲方」的评审场合，长时间看表格略累。
- 本轮只把「弱化色」`--faint` 从 `#8a8578` 提到 `#6f6b61`（AA 达标），层级关系不变。

### V2 双轨制
- 营销轨 = V1 宣纸宋韵；**控制台轨切为中性现代后台**：`#f4f5f6` 浅灰底 + `#1d2226` 深墨侧栏 + 无衬线字体栈 + 6px 圆角卡片，酒红**仅作强调色**。
- 数据密度优先：KPI 卡带迷你折线、7 日柱图、SVG 圆环占比、状态 pill、分页与表格工具栏齐备。
- 取舍：营销页与后台视觉不连续（两套语言）；最接近市面通用 SaaS 后台，品牌辨识度靠营销页承担。

### V3 碑拓墨色
- **墨色为主**：`#0f1114 / #16191d` 深墨底 + 纸白文字 `#e9e5dc`；**朱砂 `#c8402b` 是唯一亮点**，酒红 `#992222` 退为深色一档参与 hover。
- 高对比、2px 圆角、宋体、大字号字距；控制台与营销页同为深色同调，接近「数字博物馆展墙」观感；朱文占位改用**虚线朱砂边**表达透明底。
- 取舍：深色在机构采购评审会上更「先锋」，投影仪 / 低亮度屏幕下需注意对比；若后续要做大量白底打印材料，需另配浅色版。
- **本轮对比度处理（视觉取向不变）**：朱砂仍只作一种色相使用，但分两档——`--zhu:#c8402b` 保留给**图形 / 描边 / 大字号强调**（logo、`▪` 项目符、印章、`h1 em`、「已入账」等大数字），`--zhu-txt:#d97b6c`（同色相浅一档）用于**小字号正文 / 标签**，使深底最低对比度从 3.13:1 提到 5.18:1；次要文字色 `--txt3` 由 `#7c776d` 提到 `#98958d`。
